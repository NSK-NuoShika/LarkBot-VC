# LarkBot

## 项目介绍

本程序为飞书中间层，介于用户与自动化程序之间进行消息转发。下游程序通过在注册本程序接口向用户提供服务、发送消息，并按时发送心跳。用户在飞书 APP 对机器人发送固定格式的命令，转发到对应的下游程序处理。

## 下游开发者指南

下游程序的完整接入说明参见 [docs/UserGuide.md](docs/UserGuide.md) 文档。

### 注册与清扫机制

- 下游在本程序进行注册时，需保证程序名全局唯一，接口名在同一程序名下唯一。否则发生覆盖。
- 下游程序须在固定时间范围内调用本程序接口发送心跳，超时将清除注册。默认值参见源码，修改参见配置文件模板。

### 接收与派发机制

- 本程序仅能接受用户发送的单聊/文本消息，对于其他消息，默认忽略。
- 用户通过`程序名 接口名 参数1 参数2 ···`的方式调用。例如，某下游接口注册为`Test echo 参数1`，则用户可发送`Test echo HelloWorld`。
- 本程序向下游转发时携带用户 ID。
- 调用下游接口派发用户命令时，如失败（含超时），则放弃当前消息，不做重试。
- 本程序原样打包多个参数给下游，不做类型转换。

### 发送机制

- 下游向用户发送消息，需要提供用户 ID。
- 发送支持文件发送，例如，txt、pdf、doc 等。文件大小限制 30MB。
- 调用飞书接口发送失败，则放弃当前消息，不做重试。

### 技术

- Python
- FastAPI
- uvicorn

### 架构设计

程序为 EDA 架构，核心部分为三个模块：

- feishu 模块通过长连接对接上游飞书，负责向用户推送消息，接收用户发送到消息。
- downstream 模块负责对接下游程序，向下游程序派发用户命令，接收下游向用户发送的消息。
- 二者间通过消息队列 Q1 和 Q2 进行数据交互。

## 部署教程

### 创建飞书应用

1. 打开飞书开放平台，创建应用；
2. 为创建的应用添加“机器人”能力；
3. 设置订阅方式为“长连接”；
4. 添加事件“接收消息”；
5. 开放权限：“获取与发送单聊、群组消息”、“读取用户发给机器人的单聊消息”、“以应用的身份发消息”、“获取与上传图片或文件资源”；
6. 记录下对应的 App ID 和 App Secret，并妥善保管。

### 安装依赖

首次运行，需先在根目录下创建虚拟环境。

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
```

> Linux / macOS 将 `.venv/Scripts` 换成 `.venv/bin`。

### 填写配置文件

复制 `.env.example` 为 `.env`，填入飞书 App ID 和 App Secret 和其他必要的可选配置。

### 启动

启动程序。

```bash
.venv/Scripts/python src/main.py
```

> Linux / macOS 将 `.venv/Scripts` 换成 `.venv/bin`。
> 
> 在 Linux 服务器上运行，为了防止 SSH 断开导致进程终止，需使用 nohup 命令启动。
